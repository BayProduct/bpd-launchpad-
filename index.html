Connect GitHub (one time per device)

This lets the app save links to your Launchpad so they show on every device. Do it once on your phone and once on your laptop.

  1. Open GitHub → new access key (signed in as BayProduct).
  2. Name it Launchpad. Set Expiration to the longest option.
  3. Repository access → Only select repositories → pick bpd-launchpad-.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Tap Generate token, copy it, and paste it below.

Connected. Links you save, edit or delete here update every device.
